MyNBA 2K27 Creator — updated browser-only build

1. Replace the index.html in your existing GitHub repository with this one.
2. Commit the change.
3. Vercel should redeploy automatically. If it does not, open Vercel and redeploy the latest commit.
4. Hard refresh the website (Ctrl+F5) after deployment.

This version stores data in localStorage in the browser/device. It does not require Supabase. Data is not automatically shared between browsers or devices.
